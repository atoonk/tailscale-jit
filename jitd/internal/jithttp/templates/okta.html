Connect Okta

jitd signs in to Okta as an API service app: it has its own name in Okta's system log, only the scopes you grant it and its own admin role, and its key can be replaced without touching anyone's account. Do steps 1 to 5 in the Okta admin console, signed in as a super admin.

  1. Create the app. Open Applications → Applications, click Create App Integration and pick API Services. Name it jitd and save.
  2. Make a key. On the app's General tab, under Client Credentials, click Edit and set the client authentication to Public key / Private key. Click Add key, then Generate new key. Under the private key, choose PEM and copy it: Okta shows it only this once. Click Done, then Save.
  3. Turn off DPoP. Still on General, under General Settings, click Edit and untick Require Demonstrating Proof of Possession (DPoP) header in token requests. jitd does not send DPoP proofs, so Okta would refuse it.
  4. Grant the scopes. On the Okta API Scopes tab, grant okta.users.read and okta.groups.manage.
  5. Give it a role. On the Admin roles tab, assign Group Administrator, limited to the groups jitd should manage (a custom role with Manage group membership works too). The scopes say what kind of call the app may make; the role says on which groups.

    How it works

    • An approval flow can name Okta groups, with or without a posture attribute: add Okta groups under What an approval grants on the flow's page. An approval adds the requester's Okta user to each group; jitd takes them out when the access expires or is revoked.
    • That reaches whatever Okta gates by group: AWS or Google Cloud roles through single sign-on, admin roles in other apps.
    • The requester's Tailscale login is looked up as an Okta login, then as an email.
    • Someone who was in the group already stays in it: jitd only removes what it added.
    • Only groups whose members Okta manages itself. Groups filled from a directory, an app or a rule cannot be changed through the API.
    • A flow can also name okta: and a group as its requesters or approvers.
    • Okta memberships have no expiry of their own, so jitd has to be running to remove them. If a removal keeps failing, admins see it on every page.
